# Investigation Evaluations

Store dated, reproducible evaluation notes here after implementation is authorized. Each note must identify the site/evidence provenance, known dates, data quality, labelled expected findings, model/configuration, deterministic spatial inputs, limitations, and human-review criteria.

Evaluate visual interpretation, document interpretation, evidence synthesis, and uncertainty separately. Do not treat a model-confidence score as legal proof, a calibrated probability, or a substitute for provenance.
